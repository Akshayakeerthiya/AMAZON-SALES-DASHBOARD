# AMAZON SALES DASHBOARD

## PROJECT OVERVIEW

The **Amazon Sales Dashboard** is an interactive Power BI dashboard developed to analyze Amazon product sales data and generate meaningful insights into product pricing, discounts, customer ratings, and category performance.

The dashboard provides an interactive view of key business metrics and enables users to analyze product-level and category-level performance efficiently.


## TOOLS AND TECHNOLOGIES

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Transformation
- Data Visualization


## KEY PERFORMANCE INDICATORS

- Total Discounted Price
- Total Actual Price
- Average Rating
- Total Rating Count


## DASHBOARD FEATURES

- Price Range Filter
- Discounted Price by Category
- Actual Price vs Discounted Price by Product
- Top Products by Rating Count
- Average Rating by Category
- Actual Price by Category
- Interactive Data Filtering


## KEY INSIGHTS

- Analyzed product pricing across different categories.
- Compared actual prices with discounted prices.
- Identified products with high customer rating counts.
- Analyzed average product ratings across categories.
- Examined category-wise price distribution.
- Used interactive filters to analyze products within different price ranges.
